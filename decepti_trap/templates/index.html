Configuration Overview

The configuration layout for an Apache2 web server installation on Ubuntu systems is as follows:

/etc/apache2/
|-- apache2.conf
|-- conf-available/
|-- conf-enabled/
|-- envvars
|-- magic
|-- mods-available/
|-- mods-enabled/
|-- ports.conf
|-- sites-available/
|   `-- 000-default.conf
`-- sites-enabled/
    `-- 000-default.conf

The Ubuntu default configuration is a static page served from /var/www/html/.
