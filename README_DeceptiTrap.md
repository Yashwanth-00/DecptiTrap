# DeceptiTrap – Honeypot Attack Logging System

## Overview

DeceptiTrap is a lightweight cybersecurity honeypot designed to simulate vulnerable network services and capture unauthorized connection attempts. The system monitors incoming connections, records attacker information, and provides security insights through centralized logging and visualization.

The project helps security enthusiasts, students, and professionals understand attacker behavior, network reconnaissance techniques, and threat monitoring concepts in a controlled environment.

## Features

- Simulates vulnerable network services (SSH, HTTP, FTP)
- Captures unauthorized connection attempts
- Logs attacker IP addresses
- Records timestamps and targeted ports
- Stores attack data in a database
- Provides a monitoring dashboard
- Supports threat analysis and incident investigation

## Technology Stack

- Python
- Socket Programming
- Flask
- SQLite
- HTML/CSS
- Chart.js
- Threading / Asyncio

## Project Goal

Build a practical honeypot system that attracts, records, and analyzes suspicious network activity while providing useful security insights through logging and visualization.
